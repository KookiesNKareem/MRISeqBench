# Reference pulses

Every task has one reference pulse per hardware profile, generated by the pulse
authors in [`tests/fixtures/reference128_readouts.py`](../../tests/fixtures/reference128_readouts.py)
(T1/T2) and [`reference128_advanced.py`](../../tests/fixtures/reference128_advanced.py)
(T3/T4, RF). A reference qualifies when it passes the current evaluator on GPU and
its achieved image has been reviewed. Results, images and verdicts live on Ultron
under `/ssd-pool/kfareed/MRISeqBench-results/`; only the RF excitation target
(`rf_excitation_2d/target.npz`) is a tracked input.

Requalify on Ultron (GPU 3) after any evaluator, task or author change:

```bash
CUDA_VISIBLE_DEVICES=GPU-b67755a7-71f0-087b-9877-422e4b48b818 PYTHONPATH=src:. \
  .venv/bin/python scripts/qualify_references.py --out <new results dir>
.venv/bin/python scripts/reference_images.py <results dir> --out <results dir>/figures
```
