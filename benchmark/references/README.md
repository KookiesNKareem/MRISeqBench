# Reference pulses

Every task has one reference pulse per hardware profile, generated by the pulse
authors in [`tests/fixtures/reference128_readouts.py`](../../tests/fixtures/reference128_readouts.py)
(T1/T2) and [`reference128_advanced.py`](../../tests/fixtures/reference128_advanced.py)
(T3/T4, RF). A reference qualifies when it passes the current evaluator on GPU and
its achieved image has been reviewed. Store generated sequences, results, images
and verdicts in a results directory outside the source checkout. The RF excitation
target (`rf_excitation_2d/target.npz`) is a tracked benchmark input.

Requalify on a CUDA-capable GPU after any evaluator, task or reference-author change:

```bash
# Replace the example values with your GPU UUID and a new results directory.
export CUDA_VISIBLE_DEVICES="<GPU UUID>"
export MRISEQBENCH_REFERENCE_RESULTS="/absolute/path/to/reference-results"
PYTHONPATH=src:. uv run python scripts/qualify_references.py \
  --out "$MRISEQBENCH_REFERENCE_RESULTS"
uv run python scripts/reference_images.py "$MRISEQBENCH_REFERENCE_RESULTS" \
  --out "$MRISEQBENCH_REFERENCE_RESULTS/figures"
```
